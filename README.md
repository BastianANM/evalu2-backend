## Proyecto
Sitio web desarrollado con Django para mostrar una cartelera de películas de terror y slasher, con diseño responsivo y uso de Bootstrap.

## Requisitos
- Python + Django
- Entorno virtual
- Bootstrap a través de CDN
- Archivos estáticos organizados en `static/`
- Template base con navegación y home con data desde la vista
